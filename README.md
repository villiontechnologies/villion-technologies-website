## Run locally
1. Install Node.js.
2. From this folder run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Deploy
Push the project to GitHub, import it into Vercel, and deploy. Vercel provides first-class Next.js support.

## Important
Contact details are intentionally placeholders/not invented. Connect the contact form to a real company email after the domain and email are established.
